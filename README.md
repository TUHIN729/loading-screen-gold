A single loading-screen tip for stressed developers and the AI coding agents loading beside them: while the build runs, say the bug out loud — if it sounds dumb, it is, and the agent next to you just heard the answer too. Real advice (rubber-duck debugging) with a punchline that lands for both the tired human at the keyboard and the agent waiting with them.

## Run it

```sh
node main.ts
```

This writes the tip to `/output/entry.txt`.
